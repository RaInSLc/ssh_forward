## 变更审查

- 旧密码 Host 的 `credential_id` 被作为迁移兼容标记接受，解决旧 Host 阻断整个配置加载的问题。
- 新建或重新保存密码认证 Host 仍只写 DPAPI `encrypted_password`，不会继续写旧 `credential_id`。
- 启动旧密码 Host 明确要求编辑并重新输入密码；不会尝试猜测、恢复或迁移不可访问的旧密码。
- GUI 的保存失败保留表单，避免用户输入被清空和错误被掩盖。

## 安全与遗留风险

- 兼容旧 `credential_id` 是读取兼容性，不是回退到 Credential Manager；旧 Host 无密文时无法启动。
- 完全缺失密文和旧凭据 ID 的密码 Host 仍被拒绝，防止无效认证配置静默保存。
- 未修改用户现有配置、未读取任何密码或连接真实 SSH 主机。
