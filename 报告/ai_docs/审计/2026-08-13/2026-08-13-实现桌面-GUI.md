## 安全与行为审查

- GUI 中创建 Tunnel 会走核心校验，因此仅允许 `127.0.0.1` 或 `::1` 本地绑定；不提供 `0.0.0.0` 绕过入口。
- GUI 不读取密码或私钥内容。私钥认证只能保存用户输入的路径，留空则使用 SSH Agent。
- GUI 当前不暴露真实连接启动命令；禁用的“启动”按钮清楚说明后台运行时尚未实现，不会伪造 Tunnel 已连接或已运行状态。
- 默认配置路径由编译期项目根目录定位到 `config.json`，不会取决于运行时工作目录；界面可以显式切换配置路径。
- Tauri capability 仅启用 `core:default`，未添加文件系统、Shell、网络或其他高权限插件。

## 遗留风险

- CLI 和 GUI 没有跨进程写锁或统一运行时；同时修改同一配置文件时仍可能发生最后写入覆盖，需在后续守护进程或配置锁设计中处理。
- 未启动实际窗口做人工视觉检查，未执行真实 SSH 连接，原因是本次不应持续运行 GUI 或使用未授权外部 SSH 资源。
- 生产安装包构建未执行。环境中没有 Tauri CLI，本次通过 Cargo 对桌面后端和 npm 对前端资源完成构建级验证。
