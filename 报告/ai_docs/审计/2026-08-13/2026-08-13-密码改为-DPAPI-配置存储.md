## 变更范围审查

- 认证模型新增 `auth.encrypted_password` 字段，密码模式的语义校验改为要求此字段。
- 移除了桌面端的 Credential Manager `keyring` 依赖和读写代码，新增项目内 `base64` 与 Windows DPAPI API 绑定。
- GUI 保持密码认证入口，但提示已更新为 DPAPI 加密保存到配置。
- 所有修改、依赖、构建缓存及 Release 产物均位于项目目录内。

## 安全审查

- JSON 只保存 DPAPI 输出的 Base64 密文；不保存明文密码，也没有将密码写入命令行参数、日志或归档文档。
- 使用 `CryptProtectData` 和 `CRYPTPROTECT_UI_FORBIDDEN` 在当前用户作用域加密；解密后数据只在内存中传给现有 OpenSSH askpass 流程。
- DPAPI 输出内存使用后调用 `LocalFree` 释放。
- 密文不能在其他 Windows 用户或其他机器上解密；配置备份可保留，但迁移到另一设备需要重新输入密码。

## 遗留风险

- 与任何可启动 SSH 登录的软件相同，密码需要在当前进程内短暂解密；OpenSSH askpass 期间仍通过进程环境传递，后续嵌入式 SSH 后端可进一步降低暴露面。
- 旧版本仅含 `credential_id` 的密码 Host 没有可迁移的密文，必须由用户编辑并重新输入密码。
- 未使用真实 SSH 主机、真实密码或用户凭据完成端到端测试。
