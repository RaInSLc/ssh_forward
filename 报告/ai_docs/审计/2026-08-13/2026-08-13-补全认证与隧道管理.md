## 变更范围审查

- 配置模型增加 `password` 认证类型，但配置文件仍只保存 `credential_id`，不新增密码字段。
- Core 增加 Host/Tunnel 原子编辑 API；桌面端增加 Windows Credential Manager、内存运行时注册表及启动/停止命令。
- GUI 增加认证选择、密码输入、Host/Tunnel 编辑和真实 Tunnel 状态，不影响默认回环绑定限制。
- 新增 `keyring` 依赖并锁定在 `Cargo.lock`；所有依赖、缓存、构建产物均位于项目目录内。

## 安全审查

- 密码保存至 Windows Credential Manager，目标名使用 `SSHForward/` 私有前缀和随机 ID；密码没有写入 JSON、SSH 命令行参数、日志或归档。
- 密码登录通过 `SSH_ASKPASS` 读取进程环境中的内存密码；每个 Tunnel 使用独立临时脚本，退出时删除。
- 配置校验要求密码认证有非空 `credential_id`，要求私钥认证有路径；密码认证配置测试确认序列化不包含秘密值。
- Tauri capability 未增加文件系统、Shell 或网络权限；密码操作只发生在 Rust 后端。

## 遗留风险

- `SSH_ASKPASS` 临时脚本位于系统临时目录且不含密码内容，但进程环境中的密码在 OpenSSH 子进程存活期可被同权限进程读取；后续可改用嵌入式 SSH 后端降低此暴露面。
- Host Key 交互、自动重连、连接复用、守护进程和跨平台凭据库不在本次范围。
- 未使用真实 SSH 主机验证认证成功路径，未读取或处理用户密码。
