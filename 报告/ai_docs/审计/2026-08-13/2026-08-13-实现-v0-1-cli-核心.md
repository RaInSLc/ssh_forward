## 安全与规则检查

- 配置模型没有密码、口令或私钥内容字段；私钥认证仅保存路径，SSH Agent 为默认认证模式。
- V0.1 隧道仅允许 `127.0.0.1` 或 `::1` 绑定；验证中确认拒绝 `0.0.0.0`。
- OpenSSH 参数默认使用 `StrictHostKeyChecking=yes`，并启用 `ExitOnForwardFailure=yes` 和连接超时。
- 配置保存先写入临时文件并执行同步，再替换正式文件，降低写入中断损坏配置的风险。
- 五项必需归档文档均已创建；中文 Markdown 已验证为 UTF-8 无 BOM、LF 换行且无替换字符。

## 遗留风险

- `start` 以前台子进程方式运行，退出 CLI 后即停止；尚无守护进程、运行时注册、连接复用或自动重连。
- 未连接真实 SSH 主机，因此无法在本次任务中验证网络、Host Key、SSH Agent 或私钥认证的端到端行为。
- Schema 描述结构约束；Host 与 Tunnel 的引用完整性、环回绑定和认证字段等语义规则由 Rust 配置校验实现。
