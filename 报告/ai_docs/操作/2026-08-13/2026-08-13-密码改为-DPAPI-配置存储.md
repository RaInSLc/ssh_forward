- 负责人：AI

## 执行记录

1. 用户要求将密码加密保存到 JSON，并提供截图确认当前 Windows Credential Manager 中不存在旧凭据。
2. 已检查当前实现：密码认证配置只保存 `credential_id`，实际读取依赖 `keyring` crate 和 Windows Credential Manager，因此旧凭据缺失时 Tunnel 无法启动。
3. 决定改用 Windows DPAPI 加密 Base64 密文保存至 `auth.encrypted_password`，移除 Credential Manager 运行时依赖。旧 `credential_id` 不可迁移为密码，用户需在编辑服务器时重新输入密码。
4. 已将配置模型和语义校验改为使用 `encrypted_password`；桌面端改用 `CryptProtectData`、`CryptUnprotectData` 和 `LocalFree` 实现 DPAPI 加密、解密及内存释放，密文通过 Base64 保存。
5. 已移除桌面端对 `keyring` 的依赖和 Credential Manager 读写路径；更新 README 说明相同 Windows 用户与机器限制及旧配置迁移方式。
6. 已新增 DPAPI 加解密往返测试和密码配置密文结构测试。全 workspace 测试、严格 Clippy、TypeScript 检查和前端生产构建均已通过。
7. 已执行 Tauri Release Build，生成新的 `target/release/ssh-forward-desktop.exe`；独立启动检查通过，测试窗口已主动终止。
