## 执行记录

1. 用户截图显示配置校验错误：旧 Host 使用密码认证但没有 `encrypted_password`，导致 Host/Tunnel 列表为空且新服务器不能保存。
2. 已确认原因是 DPAPI 迁移将密码模式校验从 `credential_id` 改为密文后，未保留旧配置读取兼容性；这阻断了原子保存前的配置加载。
3. 将允许旧 `credential_id` Host 以迁移待完成状态加载；密码登录仍要求 DPAPI 密文，用户需要在编辑界面重新输入密码。
4. 已修改校验：密码 Host 只要具有 DPAPI 密文或旧 `credential_id` 其中之一即可加载；缺少两者仍会校验失败。
5. 已修复 GUI 保存失败后关闭表单的问题；保存失败时弹窗、输入内容和错误提示都会保留。
6. 已添加旧密码配置加载测试、更新启动迁移提示，并通过全量 Rust 测试、严格 Clippy、TypeScript 检查和前端构建。
7. 已生成并独立启动验证迁移兼容 Release 文件 `target/release/SSH-Forward-GUI-v0.1.0-dpapi-migration.exe`，测试窗口已关闭。
