# 浏览器与主题体验

- 任务名称：浏览器与主题体验
- 日期：2026-08-14
- 状态：进行中
- 负责人：AI
- 关联文件：`apps/desktop/src/App.tsx`、`apps/desktop/src/styles.css`、`apps/desktop/src-tauri/src/main.rs`、`crates/ssh-forward-config/src/model.rs`

## 目标

- 为每条 Tunnel 增加打开本地转发地址的按钮。
- 增加启动成功后自动使用系统默认浏览器打开该地址的可配置选项。
- 将界面收敛为更少的视觉信息，并提供日间与夜间主题切换。

## 范围与设计

- 自动打开状态保存到 Tunnel 配置，旧配置默认关闭，保证兼容。
- 浏览器操作使用 Tauri 系统打开能力，仅打开由本地绑定地址和端口构成的 HTTP URL。
- 日间模式作为默认视觉主题；夜间模式由用户切换，选择保存于浏览器本地存储，不写入含 SSH 设置的配置文件。

## 验证计划

1. 执行 Rust 单元测试与 Clippy。
2. 执行 TypeScript 检查和前端构建。
3. 构建桌面 Release 并验证启动。
4. 审查配置兼容性、浏览器 URL 构造和主题持久化行为。
