## 目标

按用户要求，将密码认证的密码以 Windows DPAPI 加密密文保存到 `config.json`，不再依赖 Windows Credential Manager。

## 安全设计

- 密文以 Base64 字符串保存到 `auth.encrypted_password`；JSON 中不保存明文密码。
- 使用 DPAPI 的当前用户作用域及 UI 禁用标志保护数据，只有相同 Windows 用户、同一台机器可解密。
- 启动 Tunnel 时，后端在内存中解密并传给 OpenSSH 的 `SSH_ASKPASS` 流程；不会将密码写入命令行参数、日志或归档文档。
- 原有仅包含 `credential_id` 的密码 Host 无法恢复旧密码，GUI 将提示用户编辑并重新输入密码完成迁移。

## 范围与验证

- 修改认证模型、校验、Tauri 密码处理及 GUI 提示，移除 Credential Manager 依赖。
- 添加 DPAPI 加解密和配置序列化测试，执行全量 Rust/前端检查及 Release 构建。
- 不连接真实 SSH 主机，不读取或记录用户密码。
