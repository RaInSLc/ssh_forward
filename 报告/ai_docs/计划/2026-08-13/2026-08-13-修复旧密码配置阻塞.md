## 目标

修复旧版仅含 `credential_id` 的密码 Host 被新 DPAPI 校验拒绝，导致整个配置无法加载、新服务器无法保存的问题。

## 实施范围

- 保持旧密码 Host 可加载、显示、删除和编辑。
- 旧密码 Host 只有在重新输入密码并保存后才迁移为 DPAPI 密文；不尝试恢复不存在的旧密码。
- 修复 GUI 保存失败后仍关闭表单的行为，让错误可见且用户输入保留。

## 验证计划

建立含旧 `credential_id` 的临时配置，验证可加载、可新增 SSH Agent Host、旧密码 Host 在未输入新密码时提示迁移要求；执行完整 Rust/前端检查和 Release 构建。
