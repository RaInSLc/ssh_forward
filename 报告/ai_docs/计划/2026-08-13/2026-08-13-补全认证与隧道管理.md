## 目标

补全 GUI 的密码认证保存方式，以及 Local Tunnel 的启动、停止、编辑和运行状态显示。

## 安全设计

- `config.json` 仅保存 `auth.type = "password"` 和随机 `credential_id`，绝不保存密码值。
- Windows 使用 Credential Manager 保存密码。应用通过 Windows API 读写项目私有的凭据目标名。
- OpenSSH 以 `SSH_ASKPASS` 临时脚本读取内存中的密码；密码不显示在命令行参数、日志、配置或归档记录中。
- SSH Agent、私钥路径和密码三种方式均保留；删除或切换认证方式时清除不再使用的密码凭据。

## 功能范围

- Host 新增与编辑：SSH Agent、私钥、密码认证选择。
- Tunnel 新增与编辑：Host、端点、启动与停止。
- 内存运行时注册表：记录子进程与 `stopped`、`starting`、`running`、`error` 状态。
- GUI 实时刷新运行状态和错误文本。

## 限制与风险

- 运行状态仅在 GUI 进程内有效；关闭应用会终止正在运行的 OpenSSH 子进程。
- 自动重连、连接复用、后台守护进程、Host Key 交互和跨平台密钥库不在本次范围。
- 不会连接任何真实 SSH 主机进行验证，也不会记录用户提供的密码。
