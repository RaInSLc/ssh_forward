## 交付结果

已交付基于 Tauri 2、React 和 TypeScript 的 SSH Forward 桌面端基础界面，并接入既有 Rust Core。

- 左侧 Host 列表和主区域 Local Tunnel 卡片。
- 配置文件路径切换、配置加载和校验提示。
- Host 与 Local Tunnel 的新增、删除和即时列表刷新。
- 中文表单、错误反馈、响应式窄屏布局和明确的 V0.1 运行时边界提示。
- Tauri IPC 直接复用配置和核心 crate，保留回环绑定、私钥不落盘内容等安全约束。
- Windows 图标资源、Tauri 配置、本地 npm 脚本和 GUI 启动文档。

## 使用方式

在项目根目录执行 `cargo run -p ssh-forward-desktop` 可启动桌面端；首次使用前在 `apps/desktop` 执行 `npm install` 和 `npm run build`。详细步骤已写入 `README.md`。

## 当前限制

Tunnel 运行时管理、启动/停止、连接复用、自动重连、托盘、凭据库和真实连接状态仍未实现。GUI 的启动按钮被禁用并明确说明限制，不会伪造连接状态。

## 后续建议

1. 在 Core 中实现运行时注册表、状态事件和连接池，再为 GUI 接入真实的启动、停止和状态更新。
2. 添加受控的本地测试 SSH 服务，覆盖 GUI 创建、失败反馈、端口冲突和真实本地转发路径。
3. 在运行时稳定后增加系统托盘、自动恢复和系统凭据库，并为 CLI 与 GUI 加入配置写入协调。
