# 实现 V0.1 CLI 核心

- 任务名称：实现 V0.1 CLI 核心

## 交付结果

已根据初步设计的核心优先顺序，交付 SSH Forward 的首个可编译、可验证 CLI 基础实现。

- `ssh-forward-config`：配置版本、JSON 读写、原子保存和语义校验。
- `ssh-forward-core`：Host 与 Local Tunnel 的增删和启动编排。
- `ssh-forward-ssh`：OpenSSH 本地转发参数构建、端口预检查和前台子进程控制。
- `ssh-forward` CLI：`config path|validate|show`、`host list|add|remove`、`tunnel list|add|remove`、`start <tunnel>`。
- `schemas/config-v1.schema.json` 与安全示例配置、构建和使用说明。

## 限制

当前 `start` 仅在 CLI 进程前台运行，尚未实现连接复用、多隧道运行时管理、自动重连或后台服务。真实 SSH 转发连接尚未测试，原因见测试记录。GUI、系统托盘、凭据库、嵌入式 SSH、远程转发与 SOCKS5 保持为后续工作。

## 建议后续工作

1. 为核心添加运行时注册表和连接池，实现同 Host 的多 Tunnel 复用及明确状态模型。
2. 增加可控的本地测试 SSH 服务或经用户授权的测试主机，覆盖成功连接、端口冲突、Host Key 和认证失败路径。
3. 在核心稳定后接入 Tauri GUI、托盘与系统凭据库，保持 CLI 与 GUI 复用同一核心接口。
