# 密码改为 DPAPI 配置存储

- 任务名称：密码改为 DPAPI 配置存储
- 日期：2026-08-13
- 状态：已完成
- 负责人：AI
- 关联文件：`apps/desktop/src-tauri/src/main.rs`、`crates/ssh-forward-config/src/model.rs`、`target/release/ssh-forward-desktop.exe`

## 结果

密码认证已改为 Windows DPAPI 加密密文保存到 `config.json` 的 `auth.encrypted_password` 字段，不再依赖 Windows Credential Manager。

新的 Release GUI 已生成：`target/release/ssh-forward-desktop.exe`。请关闭旧版本后启动该文件。

## 使用说明

1. 对旧密码服务器点击编辑，选择密码认证并重新输入密码后保存。
2. 新保存的 JSON 中会看到 Base64 密文，不会看到明文密码。
3. 密文只能在当前 Windows 用户和当前机器上启动 Tunnel；复制配置到其他用户或机器后需要重新输入密码。

## 限制

本次未执行真实 SSH 登录或转发验证。旧 `credential_id` 配置无法自动恢复旧密码，必须手工重新输入一次密码完成迁移。
